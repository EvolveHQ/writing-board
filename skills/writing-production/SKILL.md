# Prepare production handoff

Read [production guidance](../../docs/production.md), current packets, page plans,
review records and the user's requested deliverables. Use
[the handoff checklist](../../templates/production-handoff.md) to record missing
vendor specifications, assets and proof work.

Run `validate`, then `python scripts/writing_board.py handoff PROJECT --output
NEW_DIRECTORY`. Inspect the exported manuscript, briefs and inventory for the
intended story revisions and languages. Include references to visual sources
and required licenses; transfer referenced assets separately when authorized.

Describe reading, print and EPUB acceptance criteria separately. Do not invent
printer requirements or imply that the handoff command renders finished books.
If actual assets or publishing files are supplied, inspect them and record
artifact-specific proof evidence; otherwise list that production work as pending.
Record supported continuity changes from an accepted story in the bible and
series notes. Return the handoff location, contents and remaining production work.
