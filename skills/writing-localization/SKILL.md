# Localize a story

Read [localization guidance](../../docs/localization.md), the source packet,
selected language tags and glossary. Establish the source story ID and revision
before translating. Use `cs` for Czech; preserve regional tags when specified.

Create a unique packet ID per edition and retain aligned beat IDs. Set `language`
and `source_story_id`, and record source revision and adaptation decisions.
Preserve motive, causal links, emotional intent, reader participation and factual
meaning while writing naturally in the target language. Rebuild refrains and
sound words by function when literal wording fails; update glossary choices.

Use [the localization worksheet](../../templates/localization.md) to track
reader and layout findings. Inspect accented characters, line breaks and text
zones in actual production files when available. Distinguish an agent-produced
draft from a competent speaker's review. Validate all linked editions, identify
any source drift and leave unperformed translation or layout reviews pending.
No translation service is assumed to be installed.
