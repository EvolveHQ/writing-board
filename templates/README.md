# Writing worksheets

Copy only the worksheets useful for the current task into your private workspace.
They support exploration and review; project JSON remains the structured source.
Summarize adopted decisions there. Supplemental worksheets are not automatically
included in a project bundle or handoff.

| Worksheet | Purpose |
| --- | --- |
| [Premise alternatives](premise-alternatives.md) | Compare different story engines before drafting. |
| [Character dossier](character-dossier.md) | Develop a character with sourced facts and explicit unknowns. |
| [Location and map notes](location-map.md) | Keep geography, routes and travel assumptions consistent. |
| [Scene and art brief](scene-art-brief.md) | Plan a spread's action, text, image and physical continuity. |
| [Review](review.md) | Record findings and repairs against a specific revision. |
| [Read-aloud log](read-aloud.md) | Capture spoken rhythm, comprehension and participation observations. |
| [Localization](localization.md) | Track adaptation choices and per-language review. |
| [Production handoff](production-handoff.md) | Specify actual deliverables and proof evidence. |
| [Timeline CSV](timeline.csv) | Compare chronological events with presentation order. |
| [Series arc CSV](series-arc.csv) | Follow character or subplot changes across books or episodes. |
| [Style sheet CSV](style-sheet.csv) | Record preferred terms and spellings per language. |
| [Continuity log CSV](continuity-log.csv) | Track a fact, prop or relationship and the event changing it. |

CSV files provide columns rather than invented sample facts. Add one row per
observation or event. Keep source references specific enough for another writer
to locate the evidence.
